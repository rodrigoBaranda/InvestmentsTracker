# InvestmentsTracker — Frontend

React + Vite frontend for the InvestmentsTracker dashboard.

## Dev server

```bash
npm install
npm run dev      # http://localhost:5173
```

## Tests

```bash
npm test         # run Vitest unit tests
```

## Build

```bash
npm run build    # output to dist/
npm run preview  # preview production build locally
```

Deployed to Vercel automatically on push to `dev`. Vercel config lives in `vercel.json` at the repo root.
